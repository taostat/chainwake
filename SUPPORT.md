# Support

Start with the repository documentation and existing issues.

- For reproducible defects, use the bug report template.
- For new integrations or behavior, use the feature request template and
  describe the user outcome.
- For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and report
  privately.
- For account, billing, hosted-service, or private RPC incidents, use your
  existing Blockmachine support channel rather than a public repository issue.

Include the Chainwake version, Python version, chain, provider, minimal
reproduction, and redacted logs. Never post credentials, private keys, customer
data, or complete authenticated RPC URLs.
