# Blockmachine Chainwake

Chainwake is installed and enabled. Restart the Hermes gateway, then ask Hermes
what Blockmachine Chainwake can do, or explicitly load
`blockmachine-chainwake:chainwake` for an event-driven Bittensor wake.

The first watcher creates an isolated Python environment inside the plugin
checkout. No Blockmachine API key is required for the anonymous free tier.
